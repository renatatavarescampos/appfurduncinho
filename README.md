# APP Furduncinho

Painel da gestora financeira: solicitação e aprovação de pagamentos, conciliação bancária e fluxo de caixa.

- `index.html` abre a Central de Clientes
- `central-clientes.html` é o painel principal (abre os apps dos clientes dentro dele)
- `demo-fluxo-caixa.html` é o app de pagamentos de exemplo
- `demo.html` é a versão de demonstração anterior

Os dados ficam salvos no navegador de quem usa (localStorage); nada é enviado para servidor.
